
# Portafolio "Personal"

Proyecto de creación de un Portafolio en Flutter/Dart sobre la compañia ficticia L. Corp del juego Lobotomy Corporation, creado por Project Moon.

Para la materia de programación 3.

## Instalación

### Necesitas para ejecutarlo
- Un editor: Como [VS Code](https://code.visualstudio.com/) con la extensión **Flutter**

o
- [Android Studio](https://developer.android.com/studio) con el plugin Flutter

Y verificas si todo esta instalado usando

```bash
  flutter doctor
```
    
## Funciones y ejemplos de uso

La aplicación presenta un portafolio temático con varias secciones:

- **Inicio:** muestra la pantalla principal y permite acceder a otras secciones mediante tarjetas y accesos de navegación.
- **Sobre nosotros:** presenta información sobre Lobotomy Corporation.
- **Niveles de riesgo:** describe las categorías ZAYIN, TETH, HE, WAW y ALEPH.
- **Anomalías y ejecutivos:** muestra fichas con imágenes, nombres y descripciones.
- **Comentarios:** permite leer, escribir y agregar comentarios a la lista. Los comentarios escritos se borran al salir de la pantalla.
- **Empleados:** muestra un mensaje indicando que no se tiene acceso a esa sección.
- **Firma del desarrollador:** presenta información de contacto del desarrollador.

> La pantalla de Empleados es solo la funcionalidad de mostrar el acceso denegado, no hace nada extra.
